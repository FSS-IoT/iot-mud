# IoT MUD

An experimental project bridging digital text-based gameplay with physical hardware via IoT.

## Getting Started

This project uses `uv` for dependency management and environment running.

### Prerequisites
- [Python 3.12+](https://www.python.org/downloads/)
- [uv](https://astral.sh/uv/)

### Setup
```bash
# Install dependencies
uv sync --all-extras
```

### Running the Project
```bash
# Example: Run the module (to be implemented)
uv run python -m src.mud.__main__
```

### Testing
```bash
# Run all tests
uv run pytest
```
